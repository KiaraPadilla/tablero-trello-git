# Tablero de Tareas (estilo Trello simplificado)

Proyecto universitario de control de versiones con Git. Tablero de tareas
tipo Trello construido con HTML, CSS y JavaScript puro (sin frameworks, sin
backend), con persistencia en `localStorage`.

## Modulos

- **Tableros**: creacion, renombrado, eliminado y listado de tableros.
- **Tarjetas/Tareas**: gestion de tarjetas dentro de las columnas de cada tablero.
- **Usuarios/Notificaciones**: gestion de usuarios y notificaciones.

## Flujo de trabajo

Este repositorio usa Git Flow. Cada integrante trabaja su modulo en una rama
`feature/*` propia y la publica para revision mediante Pull Request hacia
`develop`.

## Guia para Colaboradores

1. Clonar el repositorio: `git clone <url>`
2. Crear una rama para tu modulo: `git checkout -b feature/nombre`
3. Hacer commits descriptivos y subir cambios: `git push origin feature/nombre`
4. Abrir un Pull Request hacia develop.
